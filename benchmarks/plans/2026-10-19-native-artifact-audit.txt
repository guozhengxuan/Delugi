Mysticeti instrumentation repair
benchmarks/patches/mysticeti-local.patch remains the complete cumulative patch against the exact upstream paper commit. Historic matched patch is preserved separately.
The old timestamp at commit-handler entry was moved into traversal of the complete linearized sub-DAG. Native blocks already contain authenticated payloads and the linearizer requires every referenced ancestor. The observer records full native block references including digest, exact transaction ordinal and verified request content. Output agreement is no longer inferred from leader(authority,round) debug names or equal counters. This endpoint precedes WAL commit-state processing, not durable fsync or VM execution.
Finite arrivals run on an independent OS thread, using a fixed scheduled timeline even when the bounded native channel blocks. Native block/certificate rules remain unchanged. Application requests record actual admission into that ingress thread, batching, native channel enqueue and materialization. The same origin-local monotonic clock supplies headline latency. Native request bytes carry 40 benchmark metadata bytes; bincode adds another 8 bytes. Useful bytes are separate. Request identity includes origin, sequence and a digest of the verified deterministic content, carried in the native authenticated block. No client-signature scheme is substituted into consensus.
The complete workload is reconstructed independently from the start record, including scheduled requests never admitted. A finite observation deadline filters later events, retaining unfinished/zero-output cohorts. Output prefix validation compares exact batch references and ordered request identities. M_out counts exact emitted native block payload bytes; U_out deduplicates unique application IDs.
Successful native TCP writes are counted once at each sender. Setup/warmup, measurement and drain totals reconcile to whole-run writes. Payload/evidence/repair traffic decomposition and per-operation cryptographic CPU are not yet instrumented; aggregate native transport totals must not be labelled a complete split resource ledger.
Full JSONL observation incurs CPU and file-I/O overhead, which is included in current measurements. Observer-overhead quantification remains an acceptance gate.

19 October local fault/CPU instrumentation increment
Both native adapters now expose a disabled-default semantic omission hook on one identity in the fixed faulty set, an explicit allowed-recipient set, a finite withdrawal time, and a separately declared attacker stream. Honest offered rate is unchanged and attacker requests receive no U_out credit. Native omission events record actual suppressed publication counts/bytes; suppressed bytes are not charged as network transmissions. Every actual send remains charged. Autobahn gates the faulty worker's initial payload messages and optionally its repair responses, keeping the primary alive. Mysticeti gates only the faulty author's signed blocks (including native block-repair replies), retaining other control traffic and relayed honest blocks. Mysticeti's data and consensus statements share a native signed block; this is not a payload-only fault model.
Ordinary protocol sign/verify/batch-verify calls have optional synchronous thread-CPU guards. Their 20-ms snapshots retain actual per-process boundaries; hashing/decoding within the guarded operation and failed attempts are included. These are neither wall-time counters nor total-process CPU. Native transport authentication, standalone hashing, storage CPU, detailed payload/evidence/repair byte allocation, retained memory, and observer-overhead qualification still need their own accounting. These baselines have no Delugi MMR proof operation.
