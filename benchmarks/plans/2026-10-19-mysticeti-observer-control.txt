Contract

--cohort-observer full (default) retains the detailed finite-cohort journal and
schema2/SQLite reduction. compact suppresses per-request timing and journal rows.
Both execute the same native generator, validation, linearizer, commit handler,
storage, network, repair, crypto and existing upstream metrics. Both pay for the
same finite membership bitmaps, raw native prefix fingerprints, complete-block
checkpoints and two process-resource samples. An overhead pair therefore measures
detailed journal/timing work above that common correctness observer, not the cost
of all instrumentation relative to the untouched native artifact.

Each raw native transaction advances the receipt, including unknown application
bytes and foreign-origin metadata. Every complete native block advances the batch
receipt, including empty and unknown-only blocks. Identity uses all serialized
BlockReference bytes, never the truncated Display/Debug form. Useful credit uses
the first own-origin output's admission eligibility under the same observer lock:
pre-admission output remains ineligible after later admission, including timestamp
ties; an admitted output does not have to await its own generator batch-ready event.

The common native observer's request file latches a requested local cutoff. If a
block is active, it finishes normally before the observer freezes its prefix.
The exporter allows at most 10 seconds for this complete-block boundary; the
controller allows 12 seconds for the atomic final header. It releases the shared
lock before writing bitmap files, and native protocol execution continues. The
full journal stops with this same observer prefix. The original declared deadline,
actual prefix freeze, controller export completion, final traffic scrape and
SIGSTOP timestamp are distinct and retained. Later prefix completion is not
presented as completion by the earlier deadline. Traffic through the post-export
scrape remains charged; the scrape-to-STOP tail is explicitly unsampled. Process
CPU samples retain their actual offsets from configured boundaries. Missing
samples produce unavailable CPU, not zero. Upstream histogram latency is not a
substitute for compact cohort latency.

Receipts are source-bound observer evidence. Independent signed native WAL-tail
fidelity remains incomplete. Both new finite modes remain explicitly ineligible
for formal comparisons until that fidelity and new endpoint validation are
complete. Compact has no request latency quantiles or deadline estimates. Existing
archived full/legacy readers remain available; the local control is not silently
enabled in remote placement.

Bounds

The trusted configuration binds n <= 31 and at most 5,000,000 finite IDs per
origin before bitmap IO. Native bitmap state is approximately (sum(counts) +
6 * own_count)/8 bytes, plus small hashes/counters and buffered IO; this does not
bound native protocol/storage/runtime memory. Full mode still writes per-request
journals; compact writes one bounded checkpoint per complete block. Export uses
4096-byte chunks and a final header <= 256 KiB. Python checks trusted counts,
fixed paths, regular files/no immediate symlink, full consumed-byte hashes,
popcounts, padding, stage membership and checkpoint prefix consistency. Its
bitmap working set is O(n * 4096), not O(finite requests); disk checkpoints remain
O(native blocks). Every file has an explicit 128 GiB disk envelope. This is an
observer storage limit, not a capacity or duration claim. A complete experiment
must separately record protocol WAL growth and actual disk/RSS.
