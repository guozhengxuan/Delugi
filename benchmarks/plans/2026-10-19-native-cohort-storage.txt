Native cohort storage checkpoint — 19 October 2026

New full-observer runs no longer load a complete native journal, ledger or committee output population into Python. Mysticeti JSONL and Shoal signed plans/events are read one bounded record at a time. Autobahn's existing monolithic ledger is parsed incrementally, including skipped diagnostic arrays, before SQLite staging. Each origin's finite schedule, exact identities, observed native output ordinals and censored stages remain intact. Native payload validation and blocked materialization behavior are unchanged.

The shared native_cohort_store writes the same schema2 format as Delugi: hash-bound bounded pages and streamed indexes, strict relative paths, and small committee metadata. Rows are at most 16 KiB; native pages use at most 511 rows and 8 MiB. JSONL records are at most 4 MiB, and legacy JSON is read in 16 KiB chunks with bounded values and nesting. SQLite staging and reduction each configure a 16 MiB page cache and disk-backed temporary storage. Storage and runtime grow with requests and outputs; only postprocessing working memory is bounded by records/pages/committee size. The implementation may transiently hold several bounded pages and SQLite cache allocations. Python tracemalloc results are not total RSS.

Remote host collection emits schema2 archives; the controller checks expected replica/origin/sequence/useful-byte populations before combining child archives and reducing them. Runtime evidence streams hashed chunks up to 8 MiB directly from the host, with per-chunk/file/archive receipts and a declared 128 GiB per-host disk/file envelope. The former 64 MiB per-host ledger, 512 MiB combined-ledger, 100000-request and 256 MiB encoded-workload safeguards were whole-file limitations and are removed. Build/config publication still has a real 4 GiB bundle limit, which can constrain pregenerated Shoal signed plans. No cloud or real SSH acceptance is claimed by mocked lifecycle tests.

Mysticeti's journal can omit native-valid unknown application payloads while retaining their actual native output ordinals. The bounded reader accepts these sparse ordinals, checks every observed overlap and records the terminal ordinal as a lower bound. It does not infer a complete native output tail. Full fidelity remains incomplete unless a separate signed native WAL replay establishes it. Autobahn's full materializer receipt is checked against the complete ordinal sequence and rolling exact-output fingerprint. All protocols retain zero-output and unfinished requests; unknown or unadmitted output receives no honest useful-work credit.

Legacy in-memory replay APIs remain for historical artifacts. Autobahn compact observer mode still uses finite receipt bitmaps. Native protocol histories/custody and Autobahn's live Python materializer request/output/payload/header state remain O(N). This change does not garbage-collect missing payloads, remove repair obligations, or claim constant-memory protocol execution.
